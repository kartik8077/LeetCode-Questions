# LeetCode Questions

This repository contains my solutions to LeetCode problems as I learn and practice Data Structures and Algorithms.

The problems are focused on developing strong problem-solving skills, understanding common algorithmic patterns, writing efficient code, and improving my ability to approach coding problems systematically.

## Topics Covered

- Arrays
- Strings
- Linked Lists
- Stacks & Queues
- Sorting & Searching
- Recursion
- Hashing
- Trees
- Graphs
- Greedy Algorithms
- Dynamic Programming
- And more...

## Purpose

The main goal of this repository is to:

- Practice DSA consistently
- Understand different approaches to solving problems
- Improve time and space complexity
- Build a strong foundation for coding interviews
- Track my progress and learning journey

## Structure

Each solution is organized according to the problem and/or topic, making it easier to revisit concepts and practice similar problems.

> **Learning → Solving → Improving → Repeating**

This repository will continue to grow as I solve more problems and improve my understanding of Data Structures and Algorithms.
